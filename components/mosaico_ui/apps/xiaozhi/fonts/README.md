# XiaoZhi emotion font

Subset of Noto Emoji Regular used by the XiaoZhi screen. The scene compiler
bakes the 21 emotion glyphs into the app bundle. The full font is not embedded.

- Family: Noto Emoji
- Version: 3.005
- Copyright: 2013 Google LLC
- Upstream: <https://github.com/googlefonts/noto-emoji>
- Source file SHA-256 (full Regular, before subset): `cd07743a4c93d8da929afdd28c1d368f11da478a1093146a13610081c2a58440`
- This subset SHA-256: `4fd3163317cb431fa6b20e003d055c2d07afc2c34fe33dcf45012be843048e30`
- License: SIL Open Font License 1.1. The license text is `../../../common/fonts/OFL.txt`.

The subset keeps the same code points as `noto_emoji` in the XiaoZhi firmware:
neutral, happy, laughing, funny, sad, angry, crying, loving, embarrassed,
surprised, shocked, thinking, winking, cool, relaxed, delicious, kissy,
confident, sleepy, silly, and confused.
