# Icon sources

`thread.png` is based on the PNG linked by the
[Dashboard Icons Thread page](https://dashboardicons.com/icons/thread),
downloaded from
`https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/png/thread.png`.
The gray foreground was recolored to pure white, preserving the original alpha
channel and dimensions. The scene compiler scales it for the launcher.
